# সিস্টেম ডিজাইন — বিগিনার থেকে FAANG

বাংলায় সম্পূর্ণ, ইন্টার‍্যাক্টিভ সিস্টেম ডিজাইন কোর্স। পাঁচটা ভলিউম, ৬০+ টপিক, ৪০টার বেশি **চালিয়ে দেখার মতো** ডায়াগ্রাম ও সিমুলেশন — হ্যাশ রিং ঘোরানো, Raft ইলেকশন, রেট লিমিটারে বার্স্ট পাঠানো, ৪৫ মিনিটের লাইভ ইন্টারভিউ টাইমার।

🔗 **লাইভ সাইট — [system-design.najmulislam.dev](https://system-design.najmulislam.dev/)**

কোনো বিল্ড টুল নেই, কোনো ডিপেন্ডেন্সি নেই, কোনো ব্যাকএন্ড নেই। প্রতিটা পেজ একটাই self-contained HTML ফাইল — HTML + CSS + vanilla JS, সব ইনলাইন। GitHub Pages থেকে সার্ভ করা হয়।

- **Raft ইলেকশন** (মডিউল ২) — আট ধাপে লিডার নির্বাচন, লগ রেপ্লিকেশন, লিডারের মৃত্যু
- **রেট লিমিটার** (মডিউল ৩) — চারটা অ্যালগরিদমে বার্স্ট পাঠিয়ে Fixed window-এর ২× ফাঁক দেখুন
- **টিকিট কনকারেন্সি** (মডিউল ৩) — লক ছাড়া চালালে শেষ সিট দুজনই পেয়ে যায়
- **লিফট শিডিউলার** (মডিউল ৪) — SCAN বনাম FCFS পাশাপাশি
- **এস্টিমেশন ক্যালকুলেটর** ও **লেটেন্সি স্কেল** (মডিউল ১)
- **লাইভ প্র্যাকটিস টাইমার** (মডিউল ৫) — প্রতিটা ফেজে "এই মুহূর্তে যা করবেন"

## লোকালি চালানো

রিপো ক্লোন করে যেকোনো HTML ফাইল সরাসরি ব্রাউজারে খুললেই চলে:

```bash
git clone https://github.com/najmulislamdev/system-design.git
cd system-design
start index.html          # Windows  (macOS: open, Linux: xdg-open)
```

চাইলে যেকোনো স্ট্যাটিক সার্ভারও ব্যবহার করা যায়:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## এডিট করার নিয়ম

প্রতিটা পেজ স্বয়ংসম্পূর্ণ — `<style>` আর `<script>` একই ফাইলে। নতুন পেজ যোগ করলে বা কিছু বদলালে খেয়াল রাখবেন:

- **ডিজাইন টোকেন** — রঙ ও ফন্ট `:root` ভেরিয়েবলে (`--paper`, `--ink`, `--rule`, `--l1`…`--l5`, `--disp`, `--body`, `--mono`)। ভলিউমের অ্যাকসেন্ট রঙ: `#E24E1B` `#1F63D6` `#0E8474` `#7B4FE0` `#B07D00`।
- **ফেভিকন** — ইনলাইন SVG data URI, `<title>` এর ঠিক পরে। সব পেজে একই।
- **সাইট বার** — `<body>` এর প্রথম ব্লক (`.sitebar`)। চলতি পেজের লিঙ্কে `aria-current="page"` দিতে হয়।
- **সাইট বারের উচ্চতা ৪৬px** — মডিউল পেজে সাইডবার `top:46px` আর সেকশনে `scroll-margin-top:66px` ধরে রাখা আছে, বার বদলালে দুটোই আপডেট করবেন।
- **ফন্ট** — Google Fonts থেকে Anek Bangla, Hind Siliguri, JetBrains Mono।
- অ্যানিমেশন `prefers-reduced-motion` মেনে চলে — নতুন অ্যানিমেশনেও সেটা রাখবেন।
- রোডম্যাপের অগ্রগতি শুধু মেমরিতে থাকে (রিফ্রেশ করলে মুছে যায়) — ইচ্ছাকৃত।
